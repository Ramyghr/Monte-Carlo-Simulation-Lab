Longstaff-Schwartz Method

Optimal Stopping Problem

V(t, St) = max(Φ(St), E[e-rΔt V(t+Δt, St+Δt) | St])

At each time step, compare immediate exercise value with expected continuation value

Regression Approach

C(S) = β₀ + β₁S + β₂S² + ... (Laguerre polynomials)

Use least squares to estimate continuation value as function of current price

Backward Induction

  1. Start at maturity: V(T) = Φ(ST)
  2. Work backwards through time
  3. At each step, compare exercise vs continuation
  4. Update cashflow matrix based on optimal decision

Key Insights

When is Early Exercise Optimal?

  • American Puts: Deep in-the-money, high interest rates, low time value
  • American Calls (no dividends): Never optimal to exercise early
  • With Dividends: May exercise just before ex-dividend date

Early Exercise Premium

The difference between American and European prices represents the value of flexibility. This premium is typically:

  • 2-10% for typical at-the-money options
  • Higher for deeper in-the-money options
  • Increases with interest rates
  • Decreases with time to maturity

Computational Considerations

  • More paths = better accuracy (but slower)
  • More time steps = better exercise opportunities
  • Typical: 10,000+ paths, 50+ time steps
  • Regression quality critical for accuracy
