Variance Reduction Techniques

Compare different variance reduction techniques to improve Monte Carlo simulation efficiency. Reduce computational cost while maintaining accuracy for option pricing and risk calculations.

Variance Comparison Results

Best Method

Antithetic Variates

Principle: Use pairs of negatively correlated random variables

For each z ~ N(0,1), also use -z

  • Variance reduction: 30-50%
  • No additional computational cost
  • Works well for monotonic payoff functions
  • Easy to implement

Control Variates

Principle: Use known expectation to reduce variance

Y = X - θ(Z - E[Z])

  • Variance reduction: 50-90%
  • Requires good control variable
  • Optimal θ = Cov(X,Z)/Var(Z)
  • Stock price often used as control

Importance Sampling

Principle: Change probability measure to focus on important regions

E[f(X)] = E[f(Y) * dP/dQ]

  • Excellent for rare events
  • Complex to implement
  • Requires measure transformation
  • Used in VaR calculations

Theoretical Foundation

Variance Reduction Ratio

VRR = Var(standard) / Var(reduced)

Higher VRR means more efficient simulation

Efficiency Gain

Efficiency = 1 / (Cost × Variance)

Considers both computational cost and variance

Optimal Control Variate

θ* = Cov(X,Y) / Var(Y)

Minimizes variance of controlled estimator

Practical Considerations

When to Use Each Method

  • Antithetic: Always use if applicable (free improvement)
  • Control Variates: When good control variable available
  • Importance Sampling: For rare events or tail probabilities
  • Stratified Sampling: When natural stratification exists

Implementation Tips

  • Combine methods for maximum effect
  • Test variance reduction empirically
  • Consider computational overhead
  • Validate with known test cases
