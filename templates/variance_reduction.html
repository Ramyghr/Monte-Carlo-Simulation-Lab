Variance Reduction Theory

Variance Reduction Ratio (VRR)

VRR = Var(standard) / Var(reduced)

Measures efficiency improvement. VRR > 1 indicates variance reduction.

Antithetic Variates

Use negatively correlated pairs to cancel variance:

Var((f(z) + f(-z))/2) = (1 + ρ) Var(f(z))/2

Where ρ is correlation between f(z) and f(-z), ideally close to -1

Control Variates

Y = X - θ(Z - E[Z])
Optimal θ = Cov(X,Z) / Var(Z)

Achieves maximum variance reduction when Z is highly correlated with X

🔄 Antithetic Variates

How It Works

For each random draw z from N(0,1), also use its negative -z. The pair (z, -z) has perfect negative correlation, causing variance cancellation.

estimate = (f(z) + f(-z)) / 2
30-50%
Variance Reduction
0%
Extra Cost

Best For

  • • Monotonic payoff functions
  • • Symmetric distributions
  • • European options
  • • Any Monte Carlo simulation

🎯 Control Variates

How It Works

Use a related quantity Z with known expectation E[Z]. The difference (Z - E[Z]) provides a control that reduces variance in the estimate.

Y = X - θ(Z - E[Z])
50-90%
Variance Reduction
Low
Extra Cost

Best For

  • • Options with known Greeks
  • • Asian/barrier options
  • • Portfolios with benchmarks
  • • Any correlated control

🔍 Importance Sampling

How It Works

Change the probability measure to sample more frequently from important regions (e.g., deep out-of-money options). Correct for the measure change using likelihood ratios.

E_P[f(X)] = E_Q[f(Y) * dP/dQ]
90-99%
Variance Reduction
High
Implementation Cost

Best For

  • • Rare event simulation
  • • Tail risk calculations
  • • Deep out-of-money options
  • • Credit risk modeling
