Methodology: Cholesky Decomposition

Correlated Random Variables

Generate correlated asset returns from independent standard normals:

L * Lᵀ = Σ (covariance matrix)
correlated_returns = L * z (where z ~ N(0,I))

Portfolio Statistics

  • Expected Return: μₚ = ∑ wᵢ μᵢ
  • Variance: σₚ² = ∑∑ wᵢ wⱼ σᵢ σⱼ ρᵢⱼ
  • Sharpe Ratio: (μₚ - r) / σₚ

Diversification Benefits

Correlation Impact

  • ρ = 1.0: No diversification benefit
  • ρ = 0.0: Moderate diversification
  • ρ = -1.0: Perfect hedging possible
  • Typical stock-bond: ρ ≈ -0.2 to 0.3
