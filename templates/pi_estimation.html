Estimating π using Monte Carlo

This classic example demonstrates Monte Carlo by randomly sampling points in a square and counting how many fall inside a quarter circle. The ratio approximates π/4.

How It Works

  1. Generate random points (x, y) where both x and y are between -1 and 1
  2. Check if each point falls inside the unit circle: x² + y² ≤ 1
  3. Calculate the ratio: (points inside circle) / (total points)
  4. Multiply by 4 to estimate π (since we're using a quarter circle)
  5. As the number of samples increases, the estimate converges to π
