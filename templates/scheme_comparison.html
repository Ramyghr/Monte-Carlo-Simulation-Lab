Convergence Theory

Strong Convergence

E[|Ŝ - S|] ≤ Chᵞ
  • • Euler: γ = 0.5 (Strong order 1/2)
  • • Milstein: γ = 1.0 (Strong order 1)
  • • Both have weak convergence order 1

Error Metrics

MAE = (1/N)Σ|Ŝᵢ - Sᵢ|

Mean Absolute Error

RMSE = √[(1/N)Σ(Ŝᵢ - Sᵢ)²]

Root Mean Square Error

Exact Solution (GBM)

S_T = S₀ exp((μ - σ²/2)T + σW_T)

Closed-form solution serves as benchmark for measuring discretization error.

Theoretical Reference:

Kloeden & Platen (1992): Euler has strong order 0.5, Milstein achieves strong order 1.0 under smoothness conditions.

Methodology & Applications

Discretization Schemes

Euler-Maruyama:

Ŝ_{i+1} = Ŝ_i + μŜ_iΔt + σŜ_i√Δt·Z_i

Milstein:

+ ½σ²Ŝ_i(Z_i² - 1)Δt

Milstein includes Itô correction term for improved strong convergence

When to Use Each Scheme

Euler Scheme

  • • Quick prototyping
  • • Multi-dimensional SDEs
  • • Computational speed critical

Milstein Scheme

  • • Path-dependent options
  • • High accuracy required
  • • Barrier options pricing

Practical Considerations

  • • Cost: Milstein ~20-30% more expensive
  • • Implementation: Euler simpler to code
  • • Multi-D: Euler extends more easily
  • • Accuracy: Milstein needs fewer steps

Reference: Chen & Hong (2008) - Monte Carlo simulation in financial engineering, Section 3: Path Generation.
