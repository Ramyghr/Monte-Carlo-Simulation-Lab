Convergence Theory

Strong Convergence

E[|Ŝ - S|] ≤ Chᵞ

  • Euler: γ = 0.5 (Weak convergence order 1)
  • Milstein: γ = 1.0 (Weak convergence order 1)

Error Metrics

  • MAE: Mean Absolute Error
  • RMSE: Root Mean Square Error
  • Both measure deviation from exact solution

Theoretical Reference:

Kloeden & Platen (1992): Euler scheme has strong order 0.5, Milstein scheme achieves strong order 1.0 under smoothness conditions.

Methodology

Exact Solution (GBM)

S_T = S₀ exp((μ - σ²/2)T + σW_T)

Closed-form solution serves as benchmark for discretization error measurement.

Discretization Schemes

Euler-Maruyama:

Ŝ_{i+1} = Ŝ_i + μŜ_iΔt + σŜ_i√Δt·Z_i

Milstein:

Ŝ_{i+1} = Ŝ_i + μŜ_iΔt + σŜ_i√Δt·Z_i + ½σ²Ŝ_i(Z_i² - 1)Δt

Note: Milstein scheme includes additional correction term that improves strong convergence from 0.5 to 1.0.

Error Analysis & Applications

When to Use Each Scheme

Euler Scheme

  • Quick prototyping
  • Multi-dimensional SDEs
  • When computational speed is critical
  • For weak convergence applications

Milstein Scheme

  • Path-dependent options
  • When high accuracy is required
  • Barrier options pricing
  • Small time steps

Practical Considerations

  • Computational Cost: Milstein is ~20-30% more expensive per step
  • Implementation: Euler is simpler to implement and debug
  • Multi-dimensional: Euler extends easily, Milstein requires commutativity conditions
  • Error Reduction: Milstein can achieve same accuracy with fewer steps

Reference: Chen & Hong (2008) - Monte Carlo simulation in financial engineering, Section 3: Path Generation.

Parameter Guidelines

Realistic Ranges

  • Drift (μ): -0.2 to +0.2 (annual)
  • Volatility (σ): 0.1 to 0.6
  • Time (T): 0.1 to 5 years
  • Steps: 10 to 1000

Expected Results

  • MAE: 0.1 to 2.0
  • Improvement: 20% to 50%
  • Error Ratio: 1.2x to 2.0x

Troubleshooting

  • If improvement > 90%, check implementation
  • If errors > 10, reduce volatility or time
  • If results vary widely, increase trials
