Theoretical Convergence

Law of Large Numbers

(1/N) ∑ f(Xᵢ) → E[f(X)] as N → ∞

Monte Carlo estimates converge to the true expectation

Central Limit Theorem

√N (Ĥ_N - E[f(X)]) → N(0, σ²)

Estimation error is asymptotically normal

Convergence Rate

Error ~ O(1/√N)

To halve error, need 4× more samples

Practical Implications

Sample Size Guidelines

  • 10³: Rough estimates (±10%)
  • 10⁴: Standard accuracy (±1%)
  • 10⁵: High accuracy (±0.1%)
  • 10⁶: Research grade (±0.01%)

Dimensionality Independence

Monte Carlo maintains O(1/√N) convergence regardless of problem dimension, unlike numerical integration methods.

Confidence Intervals

Standard error = σ/√N, where σ is sample standard deviation. 95% CI: estimate ± 1.96 × standard error

Convergence in Financial Applications

Option Pricing

  • European options: Fast convergence
  • American options: Slower due to regression
  • Exotic options: Path-dependent convergence
  • Barrier options: Sensitive to monitoring

Risk Measures

  • VaR: Slower for high confidence levels
  • Expected Shortfall: Requires more samples
  • Greeks: Finite difference amplifies error
  • Credit risk: Rare event challenges

Computational Trade-offs

  • Accuracy vs computation time
  • Memory requirements
  • Parallelization benefits
  • Variance reduction impact

Error Analysis

Sources of Error

  • Statistical error: O(1/√N) from random sampling
  • Discretization error: From time stepping in SDEs
  • Approximation error: From numerical methods
  • Round-off error: From finite precision arithmetic

Error Decomposition

Total Error² ≈ Statistical Error² + Discretization Error²

Balance both errors for optimal computational efficiency

Advanced Topics

Multi-level Monte Carlo

Uses hierarchy of discretization levels to reduce computational cost while maintaining accuracy for SDE simulations.

Quasi-Monte Carlo

Uses low-discrepancy sequences (Sobol, Halton) to achieve O(1/N) convergence for smooth problems.

Weak vs Strong Convergence

Weak: Distribution accuracy (for expectations)
Strong: Path-wise accuracy (for sensitivities)
