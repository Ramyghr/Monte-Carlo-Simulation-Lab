Theoretical Foundation

Geometric Brownian Motion

dSt = μStdt + σStdWt

Models stock price dynamics with drift μ and volatility σ

Risk-Neutral Pricing

ST = S0 exp((r - σ²/2)T + σ√T·Z)

Under Q-measure, expected return equals risk-free rate

Option Payoff

Call: max(ST - K, 0)
Put: max(K - ST, 0)
💡

Implementation Details

Monte Carlo Algorithm

  1. Generate N random standard normals Z ~ N(0,1)
  2. Simulate terminal prices: ST = S0exp((r-σ²/2)T + σ√T·Z)
  3. Calculate payoffs based on option type
  4. Discount average payoff: V = e-rT·E[Payoff]
  5. Estimate standard error for confidence intervals

Convergence Rate

Monte Carlo error decreases as O(1/√N). To halve error, need 4× more simulations. Antithetic variates can reduce variance by 30-50%.

Advantages

  • Works for path-dependent options
  • Easily extends to exotic derivatives
  • Natural for multi-asset portfolios
  • Parallelizable for performance
